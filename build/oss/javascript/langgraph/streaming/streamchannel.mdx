---
title: StreamChannel
description: Use StreamChannel for local and remote stream transformer projections.
---

`StreamChannel` is the projection primitive for custom streaming data. It gives in-process consumers an iterable stream, and it can also forward pushed values to remote SDK clients when the channel has a protocol name.

In TypeScript, create an unnamed channel for local-only data, or pass a string name to also emit pushed values over the wire as `custom:<name>` events:

```ts
const local = new StreamChannel<T>();
const remote = new StreamChannel<T>("timeline");
```



## Decision Rule

Use one `StreamChannel` whenever you need a streaming projection. The only decision is whether the stream should cross the wire.

| Need | Use |
| ---- | --- |
| Data should stay in process only | `new StreamChannel<T>()` |
| Data should be available in process and over the wire | `new StreamChannel<T>(name)` |




Named channel payloads must be serializable because they are also emitted as `custom:<name>` protocol events. Keep promises, async iterables, class instances, and other in-process handles local.

## Local Channels

Local channels are available through `run.extensions`, but they are not forwarded to remote clients.

```ts
import { StreamChannel } from "@langchain/langgraph";

const progressTransformer = () => {
  const progress = new StreamChannel<{ step: string }>();

  return {
    init: () => ({ progress }),
    process(event) {
      progress.push({ step: event.method });
      return true;
    },
  };
};
```




## Wire-visible channels

Wire-visible channels are available in process through `run.extensions`, and the stream handler also forwards each `push()` as a `custom:<name>` protocol event using the channel name. Remote SDK clients consume them through `thread.extensions.<name>` or a `custom:<name>` subscription.

```ts
import { StreamChannel } from "@langchain/langgraph";

const toolActivityTransformer = () => {
  const activity = new StreamChannel<{
    name: string;
    status: "started" | "finished" | "error";
  }>("toolActivity");

  return {
    init: () => ({ toolActivity: activity }),
    process(event) {
      if (event.method === "tools") {
        const data = event.params.data as { tool_name?: string; event?: string };
        if (data.tool_name && data.event) {
          activity.push({
            name: data.tool_name,
            status: data.event === "tool-error" ? "error" : "started",
          });
        }
      }
      return true;
    },
  };
};
```




## Lifecycle

`StreamChannel` lifecycle is managed by the stream handler when the channel is returned from a transformer's `init()` method. Transformers push data, but do not close or fail the channel directly.

Both local and wire-visible `StreamChannel`s are closed or failed by the stream handler.
